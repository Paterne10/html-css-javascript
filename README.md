# HTML, CSS & JavaScript Projects

A collection of front-end projects built with plain HTML, CSS and JavaScript — no frameworks. Projects are organized by difficulty level, from beginner fundamentals to more advanced, interactive builds.

## Structure

Each project lives in its own folder with its own `index.html`, `style.css` and `script.js`.

```
/
├── beginner/
│   ├── to-do-list/
│   └── password-generator/
├── intermediate/
│   ├── quiz-app/
│   └── pricing-cards/
├── advanced/
│   └── expense-tracker/
└── README.md
```

### Beginner
- **Dicee challenge** — A simple two-player dice game: clicking "Roll" generates a random number (1–6) for each player.


### Intermediate
- **Quiz app (QCM)** — multiple-choice quiz with real-time scoring and instant feedback.
- **Pricing cards** — responsive pricing section with a monthly/yearly billing toggle.
- **To-do list** — add, complete and delete tasks; DOM manipulation basics.
- **Password generator** — generates random passwords using `crypto.getRandomValues()`.

### Advanced
- **Expense tracker** — personal expense tracker with currency formatting, a custom SVG gauge and animations.

## Goal

This repository is a personal learning log — each project focuses on a specific concept or technique (DOM manipulation, state management, animations, data formatting, etc.) and grows in complexity as skills develop.
